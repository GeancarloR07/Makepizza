# 🍕 MakePizza — Aplicación Móvil de Pedidos de Pizza

**MakePizza** es una aplicación móvil desarrollada en **Flutter y Dart** diseñada para ofrecer una experiencia fluida e interactiva en la personalización, selección y pedido de pizzas en tiempo real. Cuenta con autenticación de usuarios y persistencia de datos en la nube.

---

## 📱 Características Principales

- **Autenticación Segura:** Registro e inicio de sesión de usuarios mediante Firebase Authentication.
- **Base de Datos en Tiempo Real:** Gestión de menús, ingredientes y estados de pedidos sincronizados al instante con Cloud Firestore.
- **Consumo de APIs REST:** Integración y comunicación con servicios externos para la gestión de datos y recursos adicionales.
- **Interfaz Fluida y Dinámica:** Diseñada con componentes nativos de Flutter para garantizar una experiencia de usuario (UX/UI) óptima en Android e iOS.

---

## 🛠️ Tecnologías Utilizadas

- **Framework:** Flutter (Dart)
- **Backend / Base de Datos:** 
  - Firebase Authentication
  - Cloud Firestore (Base de datos en tiempo real)
- **Conectividad:** Consumo de APIs REST
- **Control de Versiones:** Git & GitHub
